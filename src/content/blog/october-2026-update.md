## 给自己搭了一套“助手团队”

现在日常琐事基本交给几个 AI 助手分工处理：

- Grok、Claude、ChatGPT 在 Slack 上协作，能互相分派和交接任务，几轮测试任务已经跑通。
- 新加了「购物」和「物流」两个专项助手，一个管买东西，一个管快递和寄送。
- 每天晚上 9 点自动汇总一次邮件和课程网站上的作业，生成一份中文摘要，睡前看一眼就知道接下来要交什么。

## 想把 Tesla 也接进来

下一步想让助手能读取车辆状态、做一些远程操作。比较了三种接法：

| 方案 | 费用 | 特点 |
| --- | --- | --- |
| Tesla 官方 Fleet API | 个人使用基本免费 | 要自己准备域名、做开发者配置，门槛最高 |
| Teslemetry | $30/年起 | 第三方 API 服务，不用自己折腾域名和配置 |
| Tessie | $6.99/月起 | 带 App 的第三方服务，上手最快 |

还没决定。官方 API 最便宜，但前期配置麻烦；第三方服务按年或按月付费，换来的是省心。

- 坐一次狗拉雪橇
